# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-13

### Added

- Six-stage deep research methodology (`SKILL.md`): confirm-gate, plan, factual foundation, per-item deep dive, critical/cross-cutting analysis, collate & file
- Stage 4 explicit-angle framework for evaluative questions (supporting, opposing, mechanistic, meta, adjacent)
- Source diversity checklist (5 categories, minimum 4 flagged)
- `templates/research-plan.md` — Stage 1 plan format
- `templates/findings-report.md` — Stage 5 report format
- `examples/example-report.md` — illustrative finished report with inline citations
